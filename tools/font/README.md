# Strata Pixel

Собственный пиксельный шрифт для наших игр: латиница, кириллица и грузинский, заглавные и строчные,
цифры, пунктуация, валюты, стрелки, математика и значки интерфейса. Всё нарисовано вручную по одной
сетке; TTF, WOFF2, WOFF, BMFont и JSON собираются из текстовых исходников одной командой.

```bash
npm run font          # = python3 tools/font/build.py && python3 tools/font/check.py
```

Нужны `pip install fonttools brotli pillow freetype-py` (freetype-py — только для проверки).

## Сетка и метрики

Один пиксель шрифта = 100 единиц, UPM = 1600, то есть **кегль 16 px = 1 пиксель шрифта на пиксель экрана**.
Ряды считаются от базовой линии (ряд 0 стоит на ней):

```
ряд 11  ─ ─ ─ ─ ─ ─ ─ ─   верх строки (ascent = 12)
ряд 10  ·  ·  ·  ·  ·     диакритика над заглавными (Á Ё Й) — ряды 9–10, кольцо Å до 11
ряд  8  ─────────────     выносные строчных (b d h k l), диакритика над строчными (ряды 7–8)
ряд  7  ─────────────     высота заглавных и цифр: 8 рядов (0–7)
ряд  5  ─────────────     высота строчных (x-height): 6 рядов (0–5)
ряд  3  ·  ·  ·  ·  ·     математическая ось: − + = × ÷ ← → ≈ ≠, дефис и тире
ряд  0  ═════════════     базовая линия
ряд −3  ─────────────     нижние выносные (g p q y, грузинские გ ე ვ ...)
        ─ ─ ─ ─ ─ ─ ─ ─   низ строки (descent = 4)
```

| Метрика | Пиксели | Единицы |
| --- | --- | --- |
| Кегль (em) | 16 | 1600 |
| Высота заглавных | 8 | 800 |
| Высота строчных | 6 | 600 |
| Верхние выносные | 9 | 900 |
| Нижние выносные | 3 | 300 |
| hhea / typo ascender | 12 | 1200 |
| hhea / typo descender | 4 | 400 |
| lineGap | 0 | 0 |

### Правила рисунка

- **Толщина штриха — 1 пиксель везде.** Скругления — срезанный угол в 1 пиксель (O, C, S, n, o).
- **Горизонтали чуть выше середины:** средняя черта H, E, B, Ж — в ряду 4, поэтому нижняя чаша B, Ь, Ъ больше
  верхней, как в наборных шрифтах. У строчной e перекладина в ряду 3, у A — в ряду 3 (ниже, чем у H).
- **Межбуквенный просвет — 1 пиксель:** ширина знака = рисунок + 1 пустая колонка справа.
- **Цифры табличные:** каждая цифра шириной 6, столбцы чисел не «пляшут» (счётчики в HUD не дёргаются).
- **Диакритика:** знак ставится над всей буквой с пустым рядом между ними. У каждого знака есть чётный и
  нечётный вариант, сборщик берёт тот, что совпадает по чётности с шириной буквы, — так знак стоит ровно
  по центру. Если всё же остаётся полпикселя, акут смещается вправо, гравис влево. У ď ľ ť Ľ гачек
  написан апострофом, у ţ ş — седиль, у ș ț ģ ķ ļ ņ ŗ — запятая снизу.
- **Грузинский:** та же четырёхлинейная система, что у латиницы — тело на высоте строчных, выносные вверх
  до ряда 8 и вниз до ряда −3. Формы сверены с Noto Sans Georgian; петли, слишком мелкие для 3 рядов
  (хвосты დ ლ ღ), упрощены до росчерка. Мтаврули — те же формы, уложенные в высоту заглавных:
  сборщик сам сжимает/растягивает их, убирая или удваивая ряды вертикальных штрихов, а неудачные
  (Ა Ქ Ჭ Ჶ) перерисованы вручную в `glyphs/31-mtavruli.txt`.

## Интерлиньяж

Естественная высота строки (`line-height: normal`) — **16 пикселей шрифта = 1em**. Между нижним выносным одной
строки и верхним выносным следующей остаётся 4 пустых ряда, до диакритики над заглавными — 2 ряда, так что
строки не слипаются даже в грузинском тексте, где у букв и верхние, и нижние выносные.

Чтобы пиксели оставались чёткими, межстрочное расстояние должно быть целым числом пикселей шрифта:

| Где | `line-height` | Пикселей шрифта |
| --- | --- | --- |
| Подписи, кнопки, HUD | `1` | 16 |
| Абзацы, записки, летопись | `1.25` | 20 |
| Крупные заголовки в одну строку | `1` | 16 |

## Кернинг

Кернинг считается автоматически из самих битмапов, поэтому он одинаков для всех трёх алфавитов и
пересчитывается при любой правке:

1. Для каждой пары берутся правый профиль левого знака и левый профиль правого по рядам; левый знак
   «расширяется» на ряд вверх и вниз, чтобы диагональное касание считалось касанием.
2. Если самый узкий просвет в паре больше 2 пикселей (То, Ty, Г., Р,, LT, r., «Г), пара сближается до 2,
   но не больше чем на 2 пикселя. Пары, где просвет и так 1–2 пикселя, не трогаются.
3. Цифры, пробелы и комбинируемые знаки не кернятся (цифры табличные).
4. Знаки, которые кернятся одинаково со всеми, объединяются в классы: 160 × 159 классов, 3619 классовых пар,
   12 800 пар знаков. В шрифте это GPOS `kern` (PairPos format 2).

`check.py` проверяет, что ни одна пара после кернинга не касается соседа даже по диагонали.
В CSS кернинг включается так: `font-kerning: normal` (Safari при `auto` может его отключать на мелких кеглях).

## Как пользоваться

**CSS.** Кегль — кратный 16: `16px` (1×), `32px` (2×), `48px` (3×), `64px` (4×). Тогда контуры ложатся ровно
на пиксели экрана и сглаживанию нечего размывать.

```css
.pixel-text {
  font-family: 'Strata Pixel', monospace;   /* переменная --pixel в style.css */
  font-size: 32px;                          /* 16 × целое */
  line-height: 1;                           /* или 1.25 для абзацев */
  font-kerning: normal;
}
```

На экранах с дробным `devicePixelRatio` (1.25, 1.5) кегль подбирайте так, чтобы `font-size × dpr` делился на 16,
или рисуйте текст в canvas мира и масштабируйте целиком.

**Canvas.** `ctx.font = '32px "Strata Pixel"'`, `ctx.textBaseline = 'alphabetic'`, координаты — целые.
Перед первым рисованием дождитесь `document.fonts.load('32px "Strata Pixel"')`.

**Движки.** TTF подходит Godot, Unity, GameMaker: размер 16 × n, сглаживание и хинтинг выключены, фильтрация текстуры — nearest/point.
Для движков без TTF — BMFont: `lineHeight=16`,
`base=12`, кернинг в блоке `kernings`.

## Как править

Каждый знак — блок из 12 строк (ряды 8 … −3), `#` — пиксель, `.` — пусто:

```
=== U+0431 be
.####      <- ряд 8
#....
#....
####.      <- ряд 5, высота строчных
#...#
#...#
#...#
#...#
.###.      <- ряд 0, базовая линия
.....
.....
.....      <- ряд −3
```

Опции в заголовке: `adv=` — ширина целиком, `r=` — пустые колонки справа (по умолчанию 1), `o=` — сдвиг начала
(отрицательный, если знак свисает влево, как хвост j), `w=` — ширина пустого знака (пробелы), `top=` — первый ряд
для блоков другой высоты (знаки диакритики).

Буквы с диакритикой не рисуются, а собираются строкой в `compose.txt`: `U+00C1 A + acute`. После правки —
`npm run font`: сборка пересчитает кернинг и проверит, что TTF растеризуется в FreeType пиксель-в-пиксель
как исходник на 16, 32 и 48 px во всех режимах хинтинга, без серых пикселей.

# Автотесты «Пиксельной студии 3011»

```bash
cd tools/pixel-studio/tests
npm install          # библиотеки упаковки видео для проверки MP4/WebM
node run.cjs         # около 220 проверок, около 5 минут
```

Нужен Node 18+ и Playwright с Chromium (`require('playwright')` должен находиться). Если пакетов для видео нет, проверки видео помечаются как пропущенные. Если в системе есть `ffprobe`, готовые видео проверяются им: кодек, размер, число кадров.

Флаги:

- `--only=палитр,экспорт` — только разделы, в названии которых есть эти слова;
- `--quick` — без проверок скорости и стресс-теста.

Результат:

- чек-лист в консоли (✔ / ✘ / – по каждому пункту);
- `out/REPORT.md` — тот же чек-лист с галочками;
- `out/report.json` — для сравнения прогонов;
- код выхода 0, если всё прошло, 1 — если есть ошибки.

Тест открывает `../pixel-studio-3011.html` как файл и подменяет то, что даёт просмотрщик claude.ai: вызов Claude (очередь заготовленных ответов и ошибок) и окно скачивания (файлы складываются в память теста). Чего автотест не проверяет — в [CHECKLIST.md](CHECKLIST.md), раздел «Ручные проверки».

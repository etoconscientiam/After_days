# Чек-лист «Пиксельной студии 3011»

Два уровня проверки:

1. **Автотесты** — `node run.cjs` в этой папке. Около 280 проверок по 24 разделам, около 5 минут. Отчёт с галочками пишется в `out/REPORT.md`.
2. **Ручные проверки** — то, что автотест не может сделать: живой вызов Claude, настоящее окно скачивания claude.ai, кодировщик видео внутри приложений, касания на телефоне и глазами оценить вид.

Перед выпуском новой версии: зелёный прогон автотестов + ручной чек-лист ниже.

## Ручные проверки

Отмечайте прямо здесь или в опубликованном чек-листе.

### В просмотрщике claude.ai (браузер)

- [ ] «Нарисовать» в режиме «Из текста» показывает окно разрешения; после «Разрешить» план приходит, идёт счётчик секунд, сцена рисуется
- [ ] Отказ в разрешении → «Странице не разрешено обращаться к Claude», остальная студия работает
- [ ] «Доработать» с правкой «окно больше» действительно меняет сцену
- [ ] «Палитра словами»: «ржавый закат над болотом» на 16 цветов — палитра с русским названием, от тёмного к светлому, кадр перекрашен
- [ ] Импорт палитры, скачанной с Lospec (.gpl, .hex и PNG ×1 / ×8), кнопкой и перетаскиванием на раздел «Палитра»
- [ ] Новая сцена от Claude при фишае 100% продолжается за рамку (стены и пол до углов)
- [ ] PNG 1080: окно подтверждения скачивания, файл открывается, пиксели квадратные и чёткие
- [ ] GIF: скачивается и крутится по кругу в браузере и в Telegram
- [ ] MP4 в Chrome / Edge / Safari: файл H.264, играет в Telegram и в галерее телефона
- [ ] Первая сборка видео без интернета → понятное сообщение, GIF и PNG при этом работают
- [ ] «Копировать» пресет кладёт текст в буфер (или выделяет его, если буфер запрещён)
- [ ] Ctrl+V вставляет скриншот, перетаскивание файла из проводника или Finder работает

### В приложениях Claude

- [ ] Десктоп: видео собирается как MP4; если как WebM — под кнопкой есть пометка «кодировщика H.264 здесь нет»
- [ ] Десктоп: горячие клавиши работают, когда фокус в студии
- [ ] Телефон: холст закреплён сверху, настройки прокручиваются под ним
- [ ] Телефон: ползунки, рамка кадра, лампа, элементы Shore и аннотации тянутся пальцем
- [ ] Телефон: сохранение PNG / GIF / MP4 открывает системное окно «Поделиться» или сохраняет файл

### Глазами

- [ ] Каждый из семи стилей выглядит как задумано и отличается от остальных
- [ ] Частицы, бегущие цвета и живой интерфейс Shore в GIF и MP4 выглядят живо и крутятся без шва
- [ ] «Варианты» за пару нажатий дают лук, который хочется оставить
- [ ] Шесть градиентных карт на своём фото: «Ночное видение» и «Тепловизор» узнаются сразу, «Двухтон 3011» в духе гнёта
- [ ] Палитры библиотеки (PICO-8, Game Boy, Endesga 32, Oil 6) на своём фото: узнаваемый ретро-вид
- [ ] Своё фото с фишаем 100%: края продолжаются без шва и без повторов предметов
- [ ] На Retina или 4K-экране картинка чёткая, пиксели квадратные, интерфейс Shore не размыт (в режиме «по окну» края пикселей чуть мягче, в режиме «целые» — строго чёткие)
- [ ] Шрифт Shore и аннотации (особенно плашка и выноска) читаются на светлой и на тёмной сцене
- [ ] MP4 на большом экране: края пикселей не размыты, цвета не «поплыли»

## Найдено и исправлено при отладке

- Горячие клавиши срабатывали под открытой справкой и окном сохранения → теперь при открытом окне работает только Esc.
- Поле «Уведомления» принимало −5 и 1000 → числовые поля держат свои пределы.
- Пустое числовое поле при выходе из него ставило минимум или оставалось пустым → возвращается прежнее значение.
- Правки во время сборки GIF/видео попадали в часть кадров → на время сборки окно с прогрессом и «Отменить» (Esc).
- Загрузка пресета во время проигрывания оставляла старую закреплённую палитру → палитра пересчитывается при любом изменении.
- Картинка на экране меняла размер вместе с шириной сетки (и при включении «Ровно в 1080») → «по окну» заполняет окно при любой сетке, строгий целый масштаб — кнопкой «целые».
- Тест подачи пикселя иногда падал: ждал PNG фиксированные полсекунды → тесты ждут появления файла, а не время.

Найденное раньше, в прошлых итерациях: раскладка в одну колонку на всех экранах, склейка шагов отмены, «мёртвые» зависимые ползунки, пустой список размеров GIF, пробел на галочках, дёрганье холста при наведении, двойной щелчок по дорожке, шов и повторы при дорисовке фишая.

# Слои (Strata)

Idle-кликер о срезе земли: артефакт из 3011 года лежит в земле 98 000 лет, пока над ним растёт новая жизнь и копится история. Концепт и бриф — в документе автора; этот репозиторий — рабочий прототип по нему.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173  (dev-режим: клавиша ` открывает панель)
npm run build        # проверка типов + сборка в dist/
npm run zip          # dist/ -> strata-itch.zip для загрузки на itch.io как HTML-игра
npm run sim -- 6 1 1 # симуляция баланса: часов, кликов/с, seed -> sim/out/sim_<seed>.csv
```

Dev-панель в собранной версии открывается через `?dev` в адресе.

## Структура

| Папка | Что внутри |
| --- | --- |
| `src/config/` | Все числа и тексты: материалы, превращения, эры, существа, стихии, улучшения, дерево Плотности, ритуалы, сюжет, баланс, `i18n/en.json` и `ru.json` |
| `src/core/` | Чистая логика без DOM (работает и в Node): время и эры, жизнь и тафономия, отложения, геология (P, T, k, превращения, окаменение), стихии, престиж, офлайн |
| `src/world/` | Модель среза: 360 колонок пикселей (до 320 рядов в каждой) + полноширинные «пачки» для глубоких рядов (по 10, глубже 3000 — по 100) |
| `src/render/` | Небо, поверхность, срез (ImageData, шум + палитры), артефакт, свет, финал и храм; `skins.ts` — плейсхолдер-спрайты, их можно заменить, не трогая логику |
| `src/ui/` | HUD, шторка с вкладками, подсказки, летопись, музей, записки, настройки, экран возвращения |
| `src/save/` | localStorage, автосейв каждые 30 с, версия и миграции, экспорт/импорт строкой |
| `src/audio/` | Синтез на Web Audio: дрон по эрам, клик, перезвоны пород, колокольчик окаменелости, гул, хор финала |
| `sim/` | `npm run sim`: бот играет headless и пишет CSV с временем до эр, пород, сдвигов и храма |

Ядро общается с остальным через шину событий (`layerDeposited`, `rockTransformed`, `fossilFound`, `extinction`, `eraChanged`, `noteFound`, `prestige`, `temple` и др.).

## Отступления от брифа и стартовые решения

- **Вместимость зон общая для всех видов зоны.** Поэтому в карточке вида есть кнопка «−» (отпустить: существо умирает и уходит в пул тушек). Это заодно даёт ручное «похоронить».
- **Нагрев недр длится 1 500 лет** (в брифе 200). Нефти нужно 4 000 лет в окне 60–120 °C; прогресс превращения при этом накапливается и не сбрасывается, если условие прервалось.
- **Выход пород умножается на `rockYield = 0.02`** (`balance.json`). Один ряд среза — до 360 пикселей, и с табличными выходами породы копились в сотни раз быстрее цели «2–4 уровня ветки за 1–3 минуты».
- **Рубежные удвоения** (10/25/50/100) включены только у улучшений Энергии (`"milestones": true`). У скорости времени и отложений вместо них круче рост цены (×1,35): иначе время ускорялось в десятки раз и стены эр исчезали.
- **Плотность за сдвиг** считается от собственного веса слоёв (без фундамента), делитель `2e8`. Фундамент — это k≥4 ряды × `foundationCompress 0.1`, чтобы полоса была тонкой и не давала самоускорения.
- **Окаменение**: база 3% (в брифе 0,5%), бросок при P ≥ 2 МПа (в брифе 5). С табличными значениями первая окаменелость появлялась бы через часы.
- **Отложения смешиваются на стыках зон** (окно ±18 px): иначе вода, берег и суша давали три отдельных «столба» осадков с вертикальными стенками.
- **Масштаб по умолчанию целочисленный**, как в брифе. На экране 1080p это 1× (колонна 360×640). Галочка в настройках включает дробный масштаб на всё окно.
- **Тексты записок и строк памяти — черновики-заглушки** (бриф выносит их в отдельный документ). Формат и порядок уже в конфиге.

## Баланс (первая прикидка ботом, `npm run sim -- 10 1 1`)

Бот кликает раз в секунду и покупает самое выгодное. Первый сдвиг ≈ 12 мин, эра 5 ≈ на 24-й минуте второго забега, первый храм ≈ 1 ч 55 мин после 3 сдвигов. По брифу первый храм должен быть через 6–10 ч, но это открытый вопрос п. 21. Темп сейчас определяют стоимость существ и решения бота о сдвиге, а не базовые скорости эр (их замедление в 2–3 раза почти ничего не дало). Подгонять — через `src/config/*.json` и повторные прогоны sim.

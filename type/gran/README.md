# Gran (Грань), рабочее имя

Вариативная суперсемья для кириллицы и латиницы: гротеск и антиква в одном файле, с оптическими размерами.
Сейчас это прототип 0.06 (гротеск по образцу DM Sans): H O W, a c d e f g h i l m n o p r s t u v, Ж д, кириллические Н О а о с е р из общих знаков, капитель Н О Ж: 7 знаков (H O Ж n o a д), капитель для Н, О, Ж, четыре мастера.

```bash
pip install fonttools brotli
python3 type/gran/src/build.py      # fonts/GranVF.ttf и .woff2
python3 type/gran/src/specimen.py   # specimen.html: исследование, концепция, живой шрифт, пруфы
```

## Дизайн-пространство

| Ось | Тег | Диапазон | Смысл |
| --- | --- | --- | --- |
| Оптический размер | `opsz` | 12–33 | в CSS-пикселях; `font-optical-sizing: auto` выбирает сам |
| Засечка | `SERF` | 0–100 | 0 гротеск, 50 flare, 100 антиква |

Мастера: Text/Display × Grotesk/Antiqua, по умолчанию Text Grotesk.

## Концепция

0.05. Гротеск построен по образцу, который выбрал заказчик: DM Sans (Colophon Foundry, OFL). DM Sans измерен на
opsz 14 и 33 (`tools/measure.py`), контуры Gran нарисованы заново и сверены наложением (`tools/overlay.py … mix`,
`research/calibration-overlay.png`): на H O n o a расхождение несколько единиц из 1000. Кириллицы в DM Sans нет,
Ж и д нарисованы в той же геометрической логике. Антиква — строгая пара, сверена с Source Serif 4: срезанный верх
строчных штамбов с флажковой засечкой, капля на a, наклон оси контраста 8–12°.
История попыток: `fonts/archive/` (0.01 «Грань», 0.02 «Резец», 0.03 «Лубок», 0.04 «Строгая»),
исследование Velvetyne: `research/velvetyne-study.png`.

## Как устроены исходники

- `src/masters.py` — все числа мастеров: метрики, штамбы, контраст, засечки, ловушки, апроши.
- `src/geom.py` — контуры, засечка, ловушка (`trap`), зеркалирование.
- `src/glyphs.py` — построение знаков. Каждый знак во всех мастерах имеет одну структуру точек: засечки и ловушки,
  которых нет в гротеске, схлопнуты в ноль, поэтому интерполяция совместима.
- `src/build.py` — совместная конвертация кубических кривых в квадратичные (cu2qu), мастера TTF, varLib, фичи
  `smcp`/`c2sc`, STAT, именованные начертания.

Контуры перекрываются (флаг OVERLAP_SIMPLE). Для статических начертаний перед выпуском перекрытия нужно снимать.
Хинтинга и кернинга пока нет.
